# Bhoomikesh Ukey — Creative Portfolio

A responsive, dark creative-developer portfolio made with plain HTML, CSS, and JavaScript.

## Run it on Windows
1. Download and extract this ZIP.
2. Open the `bhoomikesh-creative-portfolio` folder.
3. Double-click `index.html`.
4. The website opens in your browser. Internet is needed for the Google Fonts; the rest runs locally.

## Customize before publishing
- Replace every `your.email@example.com` with your professional email.
- Replace social `href="#"` links with your actual GitHub and LinkedIn URLs.
- Add real GitHub/demo/paper URLs to project cards.
- Add your actual college name and verify the expected graduation year.
- Check that every listed skill and project description accurately represents your work.
- Optionally add a resume PDF link.

## Files
- `index.html`: content and page sections
- `style.css`: dark theme, layout, responsive rules and animations
- `script.js`: mobile menu and placeholder-link behavior

## Publish with GitHub Pages
1. Create a GitHub repository such as `my-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. Wait for the published website URL to appear in Pages settings.
